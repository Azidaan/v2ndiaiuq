# guiaidn: локальный запуск и админ-панель

## Рекомендуемый способ: Docker

1. Установите Docker Desktop.
2. Скопируйте `.env.example` в `.env` и замените `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
3. Выполните `docker compose up --build`.
4. Откройте сайт: `http://localhost:8080`.
5. Откройте админ-панель: `http://localhost:8080/admin`.

Эти команды работают также в Windows PowerShell при установленном Docker Desktop с WSL 2.

PostgreSQL, загруженные документы и изображения сохраняются в постоянных Docker-томах. Повторная сборка контейнера их не удаляет.

## Разработка без контейнера приложения

PostgreSQL должен быть доступен по адресу из `DATABASE_URL`. После создания базы:

1. Скопируйте `.env.example` в `.env`.
2. Выполните `pnpm install`.
3. Выполните `pnpm dev`.
4. Сайт откроется на `http://localhost:5173`, API — на `http://localhost:3001`.

Схема базы применяется автоматически при старте API. Первый администратор создаётся из `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Пароль из окружения не перезаписывает существующего администратора.

## Размещение

На VPS используется тот же `docker-compose.yml`. Перед запуском задайте уникальные пароли, включите HTTPS через обратный прокси, установите `COOKIE_SECURE=true` и не публикуйте порт PostgreSQL. Приложение уже отдаёт собранный сайт, API и файлы с одного домена.
